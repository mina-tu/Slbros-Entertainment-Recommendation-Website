# 21點頁面圖片清單（給 codex 產圖用）

頁面檔：`blackjack-rules-strategy.html`
圖片資料夾：`image/blackjack-rules-strategy/`（請直接建立此資料夾）

## 運作方式

HTML 內已經寫好正式的 `<img src="image/blackjack-rules-strategy/xxx.webp">`。
圖檔還沒放進去時，會顯示一個紫色虛線佔位框，框內標示「用途 / 檔名 / 建議尺寸」。
**圖檔放進資料夾後會自動顯示，虛線框也會自動變成正式邊框，不需要改任何 HTML。**

檔名請完全照下表，副檔名 `.webp`。
